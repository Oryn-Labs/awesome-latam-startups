# Contributing

- One pull request per addition, in the right country section (or **Regional** for organizations active in several countries).
- Entries are `- [Name](link) - Short, objective description.` ending with a period. No marketing language.
- Only active organizations, programs, investors, media and communities. No individual startups: add those to the [Estartapero map](https://estartapero.io/submit) instead.
- Link to the official site. Check that the link works.
